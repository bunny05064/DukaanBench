DukaanBench — manual image generation kit

Generate 10 prompts × 3 models = 30 images by hand in Google AI Studio (free, no billing), drop each result into the card below, and this page will save it with the exact filename the evaluation pipeline expects. Nothing leaves your browser.

How to run it (about 25–35 minutes)

  1. Open aistudio.google.com → Chat (or Generate Media).
  2. At the top, pick the model: start with Gemini 3.1 Flash Image Preview. Keep the aspect ratio at 1:1 (Square) if the option appears.
  3. Press Copy prompt on a card below → paste into AI Studio → Run.
  4. Right-click the generated image → Save image as…, or simply drag the image onto the dashed box in the card. This page renames it correctly and downloads it.
  5. Move the downloaded file into JoshTalks-Eval-Challenge/q1_eval/images/.
  6. Repeat for all 10 prompts, then switch the model and repeat twice more.
  7. Take 2–3 screenshots of the AI Studio screen (model name visible + image) into q1_eval/metadata/screenshots/ — that is our proof of generation.
  8. When finished, press Download manifest and save it as q1_eval/metadata/manual_manifest.json.
